# Flash Cards — Mental Math Training

Aplikacion web për stërvitje të llogaritjes mendore me flash drills.

**Live:** https://flash-cards-9ed.pages.dev/

## Quick start

```bash
npm install
npm run dev
```

Hape: http://localhost:5173/

## Features

- Flash Calculation Training
- Settings (digits, speed, negatives, decimals)
- History tracking
- Multi-language (EN, DE)
- Audio feedback
- Mobile responsive

## Tech stack

- React + Vite
- Tailwind CSS
- Framer Motion
- React Router
- i18next
